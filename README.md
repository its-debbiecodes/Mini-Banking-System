#  ====== 🏦 **MINI BANKING SYSTEM** =====   

## 👋 About
This is a simulation banking system that adds multiple accounts, lets you view your account, deposit money, withdraw money, and delete an account

## 💾 Features
This tracker contains a menu  for choosing either to 
- add a new account
- view your account
- Deposit and withdraw money
- Delete an account
- return an automatic account number.
- calculate your total money

## 💻 Tech knowledge used
- Functions
- Modules
- While loop
- For loop
- If/Else
- JSON and file handling
- Class and OOP
- Error & Exception Handling
- __dict__
- Cls

## 📂 File Architecture
* main.py - This is where the while True menu run loop is stored. This is what the user sees most of the time.
* storage.py - This is where file handling takes place: file creation, file adding, deleting, and everything JSON and __dict__.
* task.py - This is where our functions live for easy navigation and tidy code; a lot of backend happens here.

## 🚀 How to Run
1. Clone this repository or download the source code files.
2. Ensure you have Python 3.x installed on your computer.
3. Open your terminal/command prompt, navigate to the project folder, and run:
   ```bash
   python main.py
   ```
